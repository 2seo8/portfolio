# 서현 포트폴리오 초안

## 내용 수정
- 소개 문구와 프로젝트별 글은 `content.js`에서 바꾸세요.
- 이미지는 `images/` 폴더에 넣고 해당 프로젝트의 `image` 값을 예: `"images/wongil-flow.png"`로 바꾸세요.
- `image` 값을 빈 문자열로 두면 글자 그래픽이 표시됩니다.
- `index.html`은 페이지 제목/연락처/소개 섹션을, `styles.css`는 색과 배치를 수정합니다.
- 이 폴더의 `index.html`을 브라우저에서 열면 미리 볼 수 있습니다.

## 배포
GitHub 저장소에 이 폴더의 파일을 올리고 GitHub Pages 또는 다른 정적 호스팅에 연결하면 공개 링크를 만들 수 있습니다. 저장소에 수정 내용을 올릴 때마다 사이트가 갱신되도록 설정할 수 있습니다.

## 초안에서 확인할 점
- 이름, 이메일, 기간, 역할, 결과와 프로젝트 세부 문구를 본인 확인 후 다듬어 주세요.
- 실제 자료 이미지는 `images/`에 추가하세요. 타인 개인정보와 공개가 제한된 자료는 제외하세요.
- AS 실습은 실제 배포가 아닌 설계안으로 표기했습니다.
