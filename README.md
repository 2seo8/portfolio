# 서현 포트폴리오 초안

## 파일 구조
- `index.html`: 페이지 기본 구조와 로드 파일
- `styles.css`: 색상, 글꼴, 배치, 모바일 스타일
- `content.js`: 프로젝트별 제목, 기간, 역할, 결과, 상세 내용, 도식 문구와 이미지 경로
- `app.js`: 첫 화면 타임라인과 프로젝트 상세 화면 표시
- `images/`: 실제 프로젝트 화면·산출물 이미지 보관

## 내용 수정
- 프로젝트 문구와 도식 항목은 `content.js`에서 수정하세요.
- 이미지 파일을 `images/`에 올리고 프로젝트의 `gallery` 배열에 `"images/wongil-flow.png"`처럼 경로를 추가하면 상세 화면의 갤러리에 표시됩니다. 여러 이미지를 넣으면 이전·다음 버튼으로 넘겨볼 수 있습니다.
- 첫 화면은 프로젝트별 요약을 세로로 보여줍니다. 각 항목의 “자세히 보기”를 누르면 상세 사례 화면이 열립니다.
- GitHub 저장소에 변경 내용을 Commit하면 GitHub Pages가 사이트를 다시 배포합니다.

## 공개 전 확인
- 기간, 팀 인원, 역할, 결과와 문구를 본인 확인 후 수정하세요.
- 공개 가능한 자료만 `images/`에 추가하고, 인터뷰·고객 데이터는 익명 처리하세요.
- AS 실습은 실제 배포 완료가 아니라 수업 실습 및 배포 설계안입니다.
